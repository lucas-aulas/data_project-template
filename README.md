## Estrutura de Pastas
```sh
data_project-template
├── .gitignore       # Arquivos e pastas que o Git deve ignorar
├── README.md        # Apresentação e instruções de uso do projeto
├── requirements.txt # Dependências Python necessárias
├── bin              # Scripts e executáveis do projeto
├── dashboard        # Arquivos e aplicações de visualização de dados
├── docs             # Documentação do projeto
├── notebooks        # Notebooks para análise e exploração de dados
├── secrets          # Arquivos com credenciais e informações sensíveis
└── sql              # Consultas SQL e scripts de banco de dados
```
> [!WARNING]
> Mantenha a pasta `secrets` fora do controle de versão, adicionando-a ao `.gitignore`, para evitar o envio de credenciais ao Git.
